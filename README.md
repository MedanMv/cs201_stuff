# Іменники та Дієслова

| Іменники | Дієслова |
|-------|-------|
| Станції | мають велосипеди |
| Велосипеди | стоять на станції, бувають "електричний" і "звичайний", має номер |
| Клієнт | бере велосипед, катається певний час, повертає на будь яку станцію, має ім'я, має баланс на рахунку |
| Адмін | бачить кількість велосипедів на кожній станції, бачить профіт |
| Номер | є даним велосипеда |
| Ім'я | є даним клієнта |
| Баланс | є даним клієнта, зменшується після повернення клієнтом велосипеда |
| Електричний | має вартість 5 грн/хв |
| Звичайний | має вартість 2 грн/хв |
